Aeris

Your air conditioner, in the menu bar. Control a Samsung SmartThings AC from your Mac in one click.

$ brew install --cask kashmithnisakya/tap/aeris

Update later with brew upgrade aeris.

$ curl -fsSL https://raw.githubusercontent.com/kashmithnisakya/aeris/main/install.sh | bash

No Homebrew needed. Run it again to update. Read the script.

Download Aeris.zip, unzip it and move Aeris.app to Applications. The app isn't notarized, so the first time right-click it and choose Open.

Set up in a minute

  1. Install Aeris with Homebrew, the install script or the download above.
  2. Install the SmartThings CLI, SmartThings' free official tool that Aeris uses to sign in.
    $ brew install smartthingscommunity/smartthings/smartthings
  3. Click the AC icon in your menu bar, choose Sign in with SmartThings and log in to your Samsung account in the browser. That's it — your air conditioner appears.

FAQ

Which air conditioners work?

Air conditioners connected to Samsung SmartThings — mainly Samsung Wind-Free and other Samsung smart ACs. Aeris shows only the controls your model reports.

Why do I need the SmartThings CLI?

SmartThings' personal access tokens now expire after 24 hours, and registering an app with SmartThings needs a paid developer plan. The official CLI has a free sign-in that renews itself, so Aeris uses its login. Aeris reads only the CLI's current access token and asks the CLI to renew it; it never touches the CLI's refresh token.

Where are my credentials stored?

The CLI keeps its login in ~/Library/Application Support/@smartthings/cli. Aeris stores its settings in your macOS Keychain. Aeris only talks to api.smartthings.com.

How do I uninstall?
  • Homebrew: brew uninstall --cask --zap aeris
  • Script: curl -fsSL https://raw.githubusercontent.com/kashmithnisakya/aeris/main/install.sh | bash -s -- --uninstall
Is it affiliated with Samsung?

No. Aeris is an independent, open-source project that uses the public SmartThings API. SmartThings is a trademark of Samsung.
